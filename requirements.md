# JobTaylor - MVP Product Requirements & Technical Specifications

**Version:** July 2025  MVP Ready
**Product:** Chrome extension for instant AI-powered resume tailoring

##  Product Overview

JobTaylor is a Chrome extension that helps users instantly generate tailored resumes and cover letters based on any job listing they visit online. It reads the job description directly from the page, matches it with one of the user's saved base resumes, and uses GPT-4-turbo to generate ATS-friendly, plain-text application documents in seconds.

**Core Value Proposition:** Speed, simplicity, and security in resume tailoring.
